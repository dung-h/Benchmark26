# Registries

Copies of the three registries pinned by `estimator_execution.json`: the seed registry (`seed_registry.json`), the registry authority guard (`CURRENT.json`) and the method-fidelity registry (`method_fidelity_registry_v2.json`).

`CURRENT.json` names further registries of the original study that are not included. It is kept as a pinned guard record, not as configuration.
